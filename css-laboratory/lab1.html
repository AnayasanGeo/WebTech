The purpise of CSS is to control the visual presentation and layout of web pages written in HTML

You can style a whole website from a single external stylesheet file, ensuring uniform colors, fonts, and layouts across hundreds of pages.

Reflection

What is the difference between inline, internal, and external CSS?

Inline CSS is written directly within an HTML tag to style a single element (e.g <p style= " color: red ;">), while internal CSS is placed in a block in the HTML head to format a single page. External CSS keeps code in a separate .css file linked to the HTML (< link rel= "stylesheet" href==style>), making it the industry standard for styling an entire multi-page website from one location.

Which method would you use for a website with multiple pages? Explain why

With multiple pages, it is best to use external CSS because it promotes consistency, reuse, and easier maintenance.
